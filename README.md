# PDF2Cards \
Система суммаризации и генерации учебных карточек из PDF
Проект представляет собой систему для автоматической суммаризации текста из PDF-файлов и генерации учебных карточек с вопросами и ответами. Система позволяет быстро выделять ключевую информацию, создавать карточки для повторения материала

### Цель проекта

Создать систему, которая автоматически суммаризирует текст из PDF-файлов и генерирует учебные карточки с вопросами для эффективного повторения материала.

### Задачи проекта

Разработать метод извлечения текста из PDF (включая сканированные страницы с помощью OCR). \
Реализовать суммаризацию текста для выделения ключевых идей и фактов. \
Создать алгоритм генерации карточек с вопросами и ответами на основе всего текста или конспекта.

## Запуск
1. Откройте командную строку и склонируйте репозиторий
```bash
git clone https://github.com/DariaZzz/PDF2Cards.git
```
2. Перейдите в папку проекта, создайте виртуальное окружение \
и синхронизируйте зависимости:
```bash
cd PDF2Cards
uv sync
```
3. Заполните .env по примеру:
```dotenv
# ─── LLM (Amvera) ──────────────────────────────────────────────────────────────
LLM_MODEL=gpt-4.1
AMVERA_API_URL="https://inference.waw0.amvera.ru/v1"
AMVERA_API_TOKEN="<ваш_токен>"  # ← см. раздел "Получение токенов"
```
4. Запустите код приложения
```bash
flet run main.py
```

## Получение токена
1. Зайдите на сайт [Amvera](https://cloud.amvera.ru)
2. Зарегистрируйтесь и перейдите в раздел LLM
3. Получите пакет токенов, перейдя в **GPT-4.1 -> Подписки -> Подключить пакет токенов**
4. Скопируйте токен из **GPT-4.1 -> Инфо** и вставьте в `.env`
